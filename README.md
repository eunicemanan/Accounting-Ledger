This is a Java-based Command Line Accounting Application built as a capstone project for the Year Up United App Development program. 
It helps users record and view financial transactions using a CSV file for storage. Users can add new transactions, view their spending history,
 and generate financial reports like Month-to-Date, Year-to-Date, and more.

The goal of this project is to demonstrate how Java can be used to build simple, file-based applications that handle real-world tasks like tracking money.
